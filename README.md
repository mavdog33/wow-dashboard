# WoW Dashboard — Balashotcala

A personal progression dashboard for one character: Balashotcala, a level 70
Draenei Beast Mastery Hunter on TBC Classic Anniversary.

**Live:** https://mavdog33.github.io/wow-dashboard

## What it is

- Tabs for gear (current vs Phase 2/Phase 3 targets), hit rating, soft-reserve
  and swap plans, raid boss notes, dungeons, to-do list, and reputation/badges.
- Hardcoded to one character on purpose. It is the reference design for the
  per-player dashboard the WoW Character Advisor will generate for anyone
  (Phase 3 of the shared plan).

## How it works

- One self-contained `index.html` served by GitHub Pages. No build step.
- Character data changes only when Michael reports new values in-game.
